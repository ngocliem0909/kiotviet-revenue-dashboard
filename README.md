## 📌 Tính năng chính
- 📊 7 kỳ lọc nhanh: Hôm nay, Hôm qua, 7 ngày, 30 ngày, Tháng này, Tháng trước, Tùy chọn.
- 🕒 Chuẩn hóa múi giờ Việt Nam (GMT+7), thống kê chính xác tuyệt đối từng đơn hàng.
- 🏪 Bộ lọc linh hoạt: Chi nhánh, Kênh bán hàng (TikTok, Shopee, Cửa hàng trực tiếp, Zalo COD), Trạng thái đơn.
- 📈 Biểu đồ thời gian thực (Line, Bar, Doughnut) bằng Chart.js.
- 📥 Xuất báo cáo CSV UTF-8 tương thích tiếng Việt có dấu.
